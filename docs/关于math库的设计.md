## _mm_shuffle_ps 的作用
对应汇编:
```asm
shufps xmm0, xmm1, imm8
```
其中:
- a：第一个源寄存器
- b：第二个源寄存器
- imm8：8 位立即数（bitmask）

返回一个新的 __m128。
将 a: [a0, a1, a2, a3] 和 b: [b0, b1, b2, b3] 运算后会得到一个 result: [?, ?, ?, ?]

dest[0] 从 a 里选
dest[1] 从 a 里选
dest[2] 从 b 里选
dest[3] 从 b 里选
这是硬性规则 !

然后对于 imm8, 也就是 0b00000000，两个两个一组，由于 0b00 能表示 0~3，所以刚好表示你想要选一个 float4 的哪个分量。
对应的位置映射是：
```
76543210
││││││││
││││││└┴── dest0 (来自a)
││││└┴──── dest1 (来自a)
││└┴────── dest2 (来自b)
└┴──────── dest3 (来自b)
```
